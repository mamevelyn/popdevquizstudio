POPDEV QUIZ STUDIO — OFFLINE EDITION
===================================

No Adobe Flash Player or internet connection is needed.

1. Extract ALL files from this ZIP into one folder.
2. Double-click index.html to open it in Google Chrome or Microsoft Edge.
3. Choose Question Bank, Take a Quiz, Design Studio, or Results & Scores.
4. All 1,300 reviewer questions are included: the original 850 (Sets 1-6)
   plus 450 intensive term-identification questions (Sets 7-9).
5. Select Set 7, Set 8, or Set 9 to practice the 150-term coach challenge.

IMPORT EXCEL:
- Click Import Questions.
- You can import a QuizCreator 20-row .xls template saved in our earlier
  format, or an ordinary .xlsx with Question and Answer column headings.
- The QuizCreator importer scans all question rows, even if an old End Mark
  is present at row 401.
- For a true, old binary .xls file, use Excel: Save As > .xlsx first.
- CSV and JSON backups are accepted, too.

SAVE YOUR WORK:
- Quiz edits, theme choices, and scores are stored in THIS BROWSER on
  THIS DEVICE. They do not automatically sync between computers.
- On the Results & Scores screen, click Download Full Backup to save
  all questions, settings, and history to one JSON file.
- To restore a backup, choose Import Questions, select the JSON file,
  and tick Replace my current question bank.
- Keep backup files safely. Clearing browser storage can erase local changes.

QUIZ ANSWERS:
- Matching ignores capitalization and punctuation.
- For accepted alternative answers, type Answer one | Answer two
  in the editor.
- Press Enter (or Check Answer) to immediately see whether your answer is
  correct AND the correct answer for review.
- Press Enter again (or Next Question) when you are ready to move on.
- For multiple-choice questions, choose an option and click Check Answer,
  or use Enter when an answer option is focused.
- The homepage dashboard shows all completed attempts, the latest score,
  the best score, and the average score.
- Results & Scores shows the attempt number, date, correct answers,
  and percentage score for each completed quiz.

INCLUDED SETS:
- Sets 1-6: the original 850 reviewer questions, unchanged.
- Set 7: 150 Demography and POPDEV Policy terms.
- Set 8: 150 Adolescent and Reproductive Health terms.
- Set 9: 150 Advanced POPDEV terms including ageing and nuptiality.
- The coach bank is also in POPDEV_Coach_450_Term_Questions.json so it can
  be re-imported or archived independently of the full Studio.

This is an independent, custom quiz maker, not Wondershare QuizCreator.
